# 휴대폰 견적서 호갱 판독기 (폰매니저 AI MVP)

휴대폰 교체 방법(기기변경 / 번호이동 / 자급제+알뜰폰)의 24·36개월 총비용을 비교하고, 규칙 기반 AI 상담·판매점 견적 요청·교체 시점 알림을 시험하는 정적 웹 MVP입니다.

> ⚠️ `data.json`의 모든 가격·지원금·요금제 숫자는 **예시 데이터 (실제 조건 아님)** 입니다.

- 데모: https://jeonghwanko.github.io/phone-manager-mvp/
- CRM: `/admin.html` (localStorage 저장분 보기 + CSV 내보내기)

## 호갱 판독기 (메인 `index.html`)
대리점 견적서를 붙여넣거나 사진(tesseract.js 한국어 OCR, CDN)으로 올리면 24개월 실제 총비용·숨은 비용·함정·호갱 지수(0~100)를 보여주고 공유 카드(이미지 저장/공유/복사)를 만들어요. 계산은 견적서 숫자로만 하고, 견적서에 없는 값만 `quote.js`의 `REF`(**예시 기준값**)를 쓰며 화면에 표시해요. 기존 비교 화면은 `compare.html`.

## 구성
- `data.json` — 단말 가격, 통신사별 지원금·필수요금제·부가서비스·위약금, 데이터별 요금 (여기만 고치면 됨)
- `engine.js` — 총비용 계산 (단말가 − 지원금 + 할부이자(기본 연 5.9%) + 요금 + 부가서비스 − 가족결합 + 위약금)
- `parse.js` — 자유 입력 해석 ("8만원", "KT", "내년 3월")
- `app.js` — 채팅형 상담(한 번에 한 질문, 이전/수정), 비교 카드, 규칙 기반 상담. admin.html에서 OpenAI 호환 엔드포인트·키를 넣으면 후속 질문을 LLM으로 보냄(키는 하드코딩 없음, localStorage), 견적 요청·알림 저장
- `test.js` — `node test.js`로 계산 엔진 확인

## 한계
견적 요청·알림은 브라우저 localStorage에만 저장됩니다. 실제 운영 시 서버/DB와 개인정보 처리방침, 판매점 사전승낙 확인이 필요합니다.
